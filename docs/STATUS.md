# 当前项目状态

整理日期：2026-09-14。应用版本 **0.3.1**，SQLite **schema v3**，Windows 桌面应用。

## 已实现

| 领域 | 当前能力 |
| --- | --- |
| 阅读 | 主动框选后自动翻译、流式显示、同图解释与有限追问 |
| 操作 | 停止、重试、复制完整回答、原图预览、最近截图 |
| 学习 | 项目／资料／Session 隔离、相关术语、有限记忆检索、手动保存 Memory |
| 接入 | 官方 Codex App Server、官方托管 ChatGPT 登录、实际视觉模型列表 |
| 性能 | 连续换图复用连接、精简请求、明确等待阶段与耗时 |
| 数据 | SQLite 事务迁移和升级前备份，PNG 独立保存 |
| 保留 | 最近 20 张临时截图、最多 60 条完成回答；永久截图和长期 Memory 另行保存 |

尚未配置项目或资料时也能翻译。默认不自动总结；开启自动翻译意味着之后主动采集的区域及必要上下文会发送给服务。

## 已验证与限制

- 本地自动化回归 137 项；包括旧版本行为、取消竞争、项目隔离、迁移、结果保存与协议错误。
- 官方 CLI 已测版本为 0.153.4，视觉模型样本为 gpt-5.6-luna；不意味着其他版本或所有账户都兼容。
- 十张自制 STEM 图与同图追问获得真实回答；另做同一合成目录的旧／新请求对照。
- 新目录请求完成样本约 7–12 秒；用户也曾遇到旧版本 29 秒。网络与服务排队仍可影响速度。
- 本轮没有以真实 PDF 的 10–20 张复杂正文、电路图完成全部人工验收；真实多屏、外部阅读器、保护内容仍有未测范围。
- 数学显示是常见表达的可读文本转换，不是完整 LaTeX 排版器。
- 尚未提供 OCR、内置 PDF 阅读器、云同步、长期图片图库或 Memory 编辑／删除界面。
