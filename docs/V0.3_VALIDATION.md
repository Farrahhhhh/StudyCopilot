# V0.3 验证记录

日期：2026-09-10。目标：用户主动框选后自动发送当前图片，真实回复直接显示在侧栏，无两次复制粘贴。

## 环境与接入

- Windows，Python 3.12.14，PySide6-Essentials 6.11.2。
- 官方 codex-cli 0.153.4，App Server stdio。
- 官方 account/read 返回 ChatGPT 登录类型；测试视觉模型为服务公布的 gpt-5.6-luna。
- 通过官方配置定义订阅 transport，关闭 WebSocket，使用 HTTP 流，避免本机 WebSocket 重连等待。
- 不读 auth.json／Cookie／Token，不创建 API Key，不改变全局 Codex 设置。
- 每个请求采用 ephemeral thread，environments=[]，无动态工具／选中能力根。返回须通过 ephemeral、readOnly、instructionSources 检查才提交图片。
- 客户端拒绝工具与权限请求，关闭继承的 MCP、应用、shell、浏览器等功能。断线、协议变更、账号或模型不符时不给出伪成功。
- 参考官方文档：[App Server](https://learn.chatgpt.com/docs/app-server)、[认证](https://learn.chatgpt.com/docs/auth)、[配置](https://learn.chatgpt.com/docs/config-file/config-reference)。

## 自动化回归

保留 V0.1／V0.2 全部行为覆盖，仅随迁移更新 schema 版本断言。新增覆盖：

- 主动截图只提交一次，翻译期间剪贴板不变。
- 流式文本只更新当前 request／thread／turn，忽略旧图片的晚到回答。
- 新图片、项目／资料改变和清除取消旧请求，旧回答不入库。
- Enter 追问、Shift+Enter 换行、有限历史、新输入草稿不被完成事件清掉。
- 停止、服务错误、额度不足、空回答、重试与模型不可用。
- 拒绝工具调用；原始错误中可能包含的正文／凭据不展示。
- schema v2 → v3 的可读备份、旧行保留、迁移事务回滚。
- 最近回答 60 条限制、图片删除联动、旧归属拒绝保存。
- 常用公式与不支持表达式保留，结果不加载远程资源。
